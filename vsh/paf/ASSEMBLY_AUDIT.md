# ScePaf C-first assembly audit (2026-10-29)

The 34 assembly files in the pre-audit source tree were reviewed against the
project's **C means C** rule. Twenty-nine files that implemented ordinary calls,
field operations, list/tree traversal, matrix and quaternion maths, vector
polynomials, HTTP, filesystem and state operations were replaced by C. The
original NEON sine/cosine and reciprocal approximation operations are expressed
through the SDK's `<arm_neon.h>` C intrinsics, not assembly.

The former `state_abi.S` contained three complete functions. Two scalar
functions were moved to `state.c`; the third was split into a C record-copying
wrapper and a short exclusive-memory update helper. Every one of the 55
exported symbols from the removed or split assembly sources is declared in
the current C sources or retained assembly.

## Retained assembly: five small, necessary ABI/CPU boundaries

| File | What C cannot specify |
| --- | --- |
| `src/datetime/datetime_abi.S` | A parser entry receives extra state in caller register `r5`, outside the declared argument ABI. The second entry must tail-transfer `strlen`'s unmodified `r0/r1` pair. |
| `src/misc/state_abi.S` | `PafAtomicIncrementStrong` uses `dmb`, `ldrex`, and `strex` for the original exclusive-memory reference-count update. Record copying and the conditional call are C. |
| `src/std/format_abi.S` | The formatting conversion area must occupy a specific address relative to entry `sp`; portable C cannot prescribe that frame placement or its canary location. |
| `src/std/wformat_abi.S` | The wide-character formatting area similarly needs a fixed entry-stack location and canary frame. |
| `src/std/setjmp_abi.S` | Nonlocal jumps restore and scrub specific general registers, NEON registers, `sp`, and `fpscr`, which C cannot access or preserve with this ABI. |

There is no other `.S` file or C inline assembly in `vsh/paf/src`.
Instruction totals are generated by `agent/tools/status.py` into
`agent/STATUS.md`; do not maintain counts by hand.

## Verification and open work

- All 25 newly written C files compile individually with Sony SNC `-O2`
  (25 passed, zero failed) and with ARMv7 Clang and warning checks.
  The narrowed exclusive-increment assembly helper assembles for ARMv7 Clang.
- Host smoke tests cover each of six Euler quaternion variants at zero and
  nonzero angles, an identity matrix inverse, identity orthonormal frame, and
  reciprocal vector normalization.
- The CodeSourcery GCC 4.8 toolchain is available under `agent/toolchains`
  (not the default `toolchains/install`). The complete **object-library**
  targets compile with Sony SNC and the configured toolchain for CEX, TOOL,
  and DEBUGGER. Source-level `match.py` checks are now available.
- Full VELF linking, whole-module three-firmware equivalence and
  `modcheck.py` remain **unverified** while libpaf has thousands of
  unimplemented exports and its CMake target remains `PARTIAL`. By design,
  that configuration generates no module link recipe.
